# Aviv Playroom (המשחקיה של אביב)

בסיס טכני ל-Progressive Web App (PWA) בגישת Mobile-First, בנוי עם React + TypeScript + Vite.

> שלב זה כולל רק תשתית טכנית — מסך זמני בלבד, ללא עיצוב, קטגוריות, משחקים או תוכן.

## ארכיטקטורה

מבנה התיקיות מפריד בין תצוגה (React) לבין לוגיקת משחק ותוכן, כך שבעתיד יהיה אפשר
להעביר חלק מלוגיקת המשחק למנוע אחר (כמו Godot) מבלי לגעת בשכבת ה-UI:

```
src/
  app/          # רכיב השורש של האפליקציה (App.tsx) והרכבה כללית
  components/   # רכיבי React כלליים, ללא תוכן משחק קשיח
  game-core/    # חוקי משחק ולוגיקה ב-TypeScript טהור, ללא תלות ב-React
  content/      # הגדרות תוכן: קטגוריות, פריטים, רמות (יתווספו בהמשך)
  features/     # פיצ'רים/משחקים עתידיים, כל אחד בתיקייה משלו
  types/        # טיפוסי TypeScript משותפים
  utils/        # פונקציות עזר כלליות
public/
  assets/
    images/     # תמונות (יתווספו בהמשך)
    audio/      # קבצי שמע (יתווספו בהמשך)
  icons/        # אייקוני PWA (placeholder זמני בלבד כרגע)
```

## דרישות מקדימות

- Node.js גרסה 20 ומעלה
- npm

## התקנת Dependencies

```bash
npm install
```

## הפעלת סביבת פיתוח

```bash
npm run dev
```

השרת יעלה בכתובת שתוצג בטרמינל (בדרך כלל `http://localhost:5173`).

## יצירת Production Build

```bash
npm run build
```

הפלט ייווצר בתיקיית `dist/`. אפשר לבדוק אותו מקומית עם:

```bash
npm run preview
```

## בדיקה ממכשיר אחר באותה רשת מקומית (טלפון/טאבלט)

1. ודאו שהמחשב והמכשיר הנייד מחוברים לאותה רשת Wi-Fi.
2. הריצו את שרת הפיתוח עם חשיפה לרשת:

   ```bash
   npm run dev -- --host
   ```

3. בטרמינל תופיע כתובת מסוג `Network: http://<כתובת-IP-מקומית>:5173/`.
4. פתחו את הכתובת הזו בדפדפן של הטלפון/הטאבלט (Safari באייפון/אייפד, Chrome באנדרואיד).

**הערה טכנית חשובה:** גישה מרשת מקומית דרך `http://` (ולא `https://`) נחשבת
"Secure Context" חלקי בלבד בדפדפנים. טעינת האפליקציה ותצוגתה יעבדו כרגיל, אבל
חלק מהתנהגויות ה-PWA (כמו רישום Service Worker לצורך Offline מלא) עשויות שלא
לפעול במלואן עד שהאפליקציה תוגש דרך HTTPS (או `localhost`). זהו מצב צפוי בשלב
הפיתוח המקומי ואינו באג — הנושא ייבדק שוב כשהאפליקציה תעלה לסביבת אירוח אמיתית
עם HTTPS.

## התקנה למסך הבית (Add to Home Screen) — תהליך בסיסי

לאחר שהאפליקציה מוגשת דרך HTTPS (בסביבת אירוח, לא בפיתוח מקומי דרך `http`):

**iPhone / iPad (Safari):**
1. פתחו את כתובת האפליקציה ב-Safari.
2. הקישו על כפתור השיתוף (הריבוע עם החץ).
3. בחרו "הוסף למסך הבית" (Add to Home Screen).
4. אשרו — יופיע אייקון על מסך הבית שפותח את האפליקציה במצב Standalone (ללא סרגלי דפדפן).

**Android (Chrome):**
1. פתחו את כתובת האפליקציה ב-Chrome.
2. הקישו על תפריט שלוש הנקודות.
3. בחרו "הוסף למסך הבית" / "התקן אפליקציה" (Add to Home screen / Install app).
4. אשרו — האפליקציה תיפתח כאייקון עצמאי במצב Standalone.
